# Checklist example

Download [checklist.stepvela](checklist.stepvela) and choose **Open** in StepVela.

The guide was recorded from a separate Notepad window containing public demonstration text:

```text
Team handoff checklist
Record the workflow, review the steps, then save the guide.
```

Four real keyboard interactions became steps. Titles were edited in the running app, a description was added to the final step, and the final screenshot was cropped. This makes it a small example of capturing and refining a desktop instruction guide.

The `.stepvela` file is a ZIP archive containing the portable guide, JSON, Markdown, and screenshots. To view it without StepVela, copy it with a `.zip` extension, extract it, and open `report.html`.
