# Changelog

## 0.1.0 — 2026-10-14

Initial public release.

- Native mouse, scroll, and keyboard-event recording with pause/resume and global controls.
- Active-window capture by default, screenshot retention, bounded worker queue, and skipped-event reporting.
- Editable guides, step titles/descriptions, manual steps, reordering, and removal.
- Screenshot replacement, crop, highlight, solid pixel redaction, and single-operation undo.
- Saved projects and offline HTML, Markdown, JSON, and image exports.
- Warm light and charcoal dark workspaces.
- Current-user MSI with Start Menu shortcut, repair/uninstall support, and portable ZIP.

Release binaries are unsigned. Broader device testing, crash-session recovery, and code signing are planned.
